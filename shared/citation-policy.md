# Citation Policy

1. Never fabricate a reference, author, title, venue, year, identifier, quote, or BibTeX field.
2. Verify bibliographic metadata from a reliable record. Prefer the publisher, proceedings, journal, or an authoritative index; retain a preprint identifier when that is the canonical source.
3. Verify semantic support by inspecting the cited primary source, not only another paper's description of it.
4. Separate **metadata verified** from **claim support verified**. A correct BibTeX record does not establish that the paper supports the sentence.
5. Prefer primary sources for methods, results, and definitions. Use secondary sources for context and label them accordingly.
6. Distinguish published versions from preprints when versions differ; cite the version actually checked and note material differences.
7. If the source or support cannot be checked, mark it **unresolved** and state what must be verified. Never substitute a plausible paper.
8. Keep quotations short, accurate, and tied to a source location; paraphrases still require support.

Use [evidence-policy.md](evidence-policy.md) to assess the strength of claims supported by citations.
