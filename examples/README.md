# Examples

This directory intentionally contains no personal or project-specific research examples in v0.1.

Future examples must use one of the following:

- Synthetic data created solely to demonstrate an artifact or workflow.
- A small toy research problem with invented, clearly labeled illustrative values.
- A fully public benchmark task, with the source, version, and applicable license or terms identified.

Do not add personal or institutional details, unpublished-project methods, private experiment results, confidential reviewer material, proprietary datasets, credentials, or identifying file paths. Never present illustrative values as empirical findings. Keep private project context outside this public repository.
