# Venue Profiles

These profiles offer brief scope orientation only. Tracks, topic definitions, and policies change; a scope summary does not establish fit or eligibility.

Before submission, verify the **current official** call for papers or aims and scope, formatting rules, page limits, anonymity policy, supplementary-material rules, required declarations, and official LaTeX template. Check the exact year, track, and article type. Record the official URL and date checked in project notes outside this repository.
